# Operations change practice pack

Use this optional guidance only for an explicitly declared, executed, and verified operational outcome. Ordinary Cartopian lifecycle activity is excluded. Selection does not change risk, activate judgment guidance, or require review.

## Rehearsal

Before the live action, exercise the sequence and decisive checks in the closest safe environment available. Confirm prerequisites, authority, owners, timing, stop conditions, and the expected before-and-after state. Record material differences between rehearsal and execution.

## Handoff

Name the outgoing and incoming owners, the state being transferred, acceptance evidence, open conditions, and the time or event when responsibility changes. Verify receipt or acceptance; sending instructions alone is not a completed handoff outcome.

## Rollback

Define the rollback trigger, authority, exact action, state dependencies, data consequences, and proof of recovery. Check compatibility with the current state and identify the point after which rollback is unavailable or must become a different contingency.

## Monitoring

Name the signals that prove the new state is serving its purpose, their source, observation window, thresholds, and owner. Include silent-failure indicators and a stop or escalation condition. Verify the running state directly rather than inferring it from a completed command.
